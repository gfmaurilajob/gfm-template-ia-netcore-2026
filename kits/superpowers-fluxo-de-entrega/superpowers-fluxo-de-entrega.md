# Superpowers: o fluxo de entrega

Sete skills do Superpowers, de Jesse Vincent (licença MIT), na ordem em que se usam depois que o plano está pronto:

1. **Git worktrees**: o trabalho acontece numa área isolada.
2. **Desenvolvimento com subagentes**: um agente novo por tarefa, com revisão depois de cada uma.
3. **Executar plano**: a alternativa na própria sessão, quando não há subagentes.
4. **Pedir revisão de código**: um revisor separado olha o resultado.
5. **Receber revisão de código**: cada sugestão conferida no código antes de aplicar.
6. **Verificar antes de concluir**: nada é dado como pronto sem a prova rodada.
7. **Finalizar branch**: teste verde, e você escolhe entre merge, pull request ou guardar.

As skills de executar plano e de subagentes compartilham scripts e o modelo de revisão: instale todas juntas.
