# Kit de engenharia de contexto para agentes

Três skills da coleção Agent Skills for Context Engineering, de Muratcan Koylan e colaboradores (licença MIT), na ordem em que se usam:

1. **Fundamentos**: o que é contexto e como a atenção do modelo funciona.
2. **Diagnóstico de degradação**: os padrões de falha e como corrigir a causa.
3. **Otimização**: orçamento, compactação, mascaramento e cache para gastar menos.

Original: https://github.com/muratcankoylan/Agent-Skills-for-Context-Engineering
